# ARGUS — From October Evidence to December Integration

**Purpose:** A practical, community-oriented plan accompanying the October 2026 Vesuvius Progress Prize entry. *The plan does not replace the verified October evidence.*

**Proved in October (storage-state endpoint only):** A frozen 24-cell PHerc. 211 local sample; 13 stored prediction chunks; 19,932,389 positive labels; 8,519,612 labels mapping to absent masked-CT chunk objects (42.74% of the positives in those stored chunks); independent re-decoding and a full record of missing samples. This is **not** physical papyrus absence or ink identification.

**Critical path:**

| When | What must be done | Gate |
|---|---|---|
| Oct 23–31 | License, reproducibility, public source release, October submission | Public commit and valid evidence |
| Nov 2–6 | Matched benchmark vs existing phantom-audit work | Distinct value or pivot upstream |
| Nov 9–13 | Verify geometry and mask semantics | Registered / not / unresolved |
| Nov 16–20 | One actionable triage demonstration | Practical downstream researcher decision |
| Nov 23–30 | Prespecified independent region/scroll | Complete or openly reported failure |
| Dec 1–11 | Cross-platform reliability, replay, review request | Reproducible install and schema |
| Dec 14–18 | Stable release / upstream contribution / technical note | Maintain, merge or retire decision |
| Dec 21–31 | Follow-ups and contingency | End-of-year report |

**Community contribution, not solicitation:** I recognise the existing baseline and welcome correction, reproduction, and suggestions for useful integrations. I aim to maintain a small useful feature or merge it upstream regardless of the prize outcome; I am not asking for private access, endorsement or a position. If technical validation fails, the failure and limited claim will be documented.
