# Release checklist and scientific gates

## Source publication gate

- Actual source, tests, protocol, evidence, figures and research files accessible on GitHub.
- Unit tests, frozen dry-run, installed CLI and release checks executed; record actual platform/version results in VALIDATION.md.
- CI runs offline on Windows/Linux with Python 3.11/3.13; verify the exact commit before merging.
- Manifest hashes, local links and scoped MIT terms checked; no credentials or new raw data introduced.
- Preserve existing public archives and history; disclose unresolved prediction-asset redistribution rights.

## Research limitations (not claims of completed work)

- Independent physical registration and unmasked CT support: unverified.
- Full prior-art pipeline benchmark and demonstrated downstream benefit: not completed.
- Independent external researcher replication and external preregistration chronology attestation: absent.
- Broader library/API/tifxyz regression coverage: limited; passing held-out tests do not certify all modes.

The narrow storage-audit contribution may be submitted for consideration with these limits disclosed. No prize eligibility, acceptance, scientific endorsement or award is promised. Submission and contacting researchers are separate user decisions. Raw captures are excluded from new release assets pending asset-specific rights review.
