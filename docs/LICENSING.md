# Code, data and dependency licenses

New ARGUS code is distributed under the accompanying MIT grant. The grant excludes
third-party source data, data-derived models/figures and any unlicensed legacy material.
No upstream phantom-audit
code is bundled; its pinned pure function was inspected separately for comparison.
Blosc2, NumPy, numcodecs, tifffile and optional upstream villa retain their own terms.

The AWS Vesuvius CT dataset registry lists CC BY-NC 4.0:
https://registry.opendata.aws/vesuvius-challenge-herculaneum-scrolls/ . Prediction
asset-specific notices must be checked before redistributing raw or derived data.
New source-only release assets exclude captured archives and research-history files.
The repository retains an unchanged capture that was public before this source release.
See [data rights and prior art](DATA_RIGHTS_AND_PRIOR_ART.md) for attribution,
unresolved prediction-asset terms and the disposition of the historical public capture.
