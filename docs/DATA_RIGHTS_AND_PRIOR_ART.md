# Data rights, attribution and prior art

Original ARGUS software and original project-authored prose are MIT licensed under [LICENSE](../LICENSE). That grant excludes third-party code, source CT/prediction assets, and data-derived scientific imagery. Dependencies retain their own licenses; no upstream phantom-audit source is vendored.

PHerc.211 source data are provided by the Vesuvius Challenge / ScrollPrize open-data project. Consult the [official data page](https://scrollprize.org/data), [open-data citation instructions](https://github.com/ScrollPrize/open-data#citation), and [AWS registry](https://registry.opendata.aws/vesuvius-challenge-herculaneum-scrolls/) (CC BY-NC 4.0). These registry terms concern the dataset and do not by themselves settle every separately produced prediction asset's terms. Scientific figures reproduce/derive from identified prediction bytes and retain underlying attribution and restrictions; they are not offered as MIT data.

The existing public repository already contained ARGUS_04_HELDOUT_CAPTURE.zip with 13 compressed prediction chunks and HTTP receipts. This release leaves both pre-existing public archives at their original root paths, with no archive changes in the publication branch. Independent local backups and SHA256 hashes were checked. It does not add new raw data, imply that historical publication settled permission, or expand MIT to these bytes. Asset-specific redistribution rights remain unresolved. Do not attach that historical capture to a new source release or mirror it elsewhere without checking those terms. Git history is not rewritten.

Schurkai's [vesuvius-phantom-audit](https://github.com/Schurkai/vesuvius-phantom-audit) already provides chunk- and voxel-level checks and cleanup. ARGUS claims neither priority for that problem nor measured superiority. Intended complementary features are frozen local selection, hashes, request receipts and separately implemented counters. A pinned overlap-function-only comparison agreed for 24/24 cells; that is not a full pipeline or performance benchmark. See [baseline](BASELINE_AND_NOVELTY.md) and [pinned source record](UPSTREAM_SOURCE_RECORD.json).

Absent masked-CT storage is not proof of absent physical papyrus. Independent registration, unmasked CT interpretation, physical surface identity, ink and writing remain unverified. No endorsement, prize decision or external researcher replication is implied.
